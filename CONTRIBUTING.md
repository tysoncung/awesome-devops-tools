# Contributing to Awesome DevOps Tools

Thank you for your interest in contributing to Awesome DevOps Tools! This repository aims to be a comprehensive resource for the DevOps community.

## How to Contribute

### Adding a New Tool

1. **Check if it already exists** - Search the README to avoid duplicates
2. **Find the right category** - Place the tool in the most appropriate section
3. **Use the correct format**:
   ```markdown
   - **[Tool Name](https://link-to-tool)** - Brief description (max 1-2 lines) #opensource (if applicable)
   ```

### Tool Inclusion Criteria

Tools should meet these criteria:
- ✅ Actively maintained (recent updates within last 2 years)
- ✅ Production-ready or stable release
- ✅ Clear documentation available
- ✅ Relevant to DevOps practices
- ✅ Used by or useful to the DevOps community

### Creating New Categories

If you believe a new category is needed:
1. Open an issue first to discuss
2. Provide at least 5 tools for the category
3. Explain why existing categories don't fit

## Formatting Guidelines

### Tool Entries
- **Name**: Official product name with proper capitalization
- **Link**: Official website or GitHub repository
- **Description**: Concise, factual description
- **Tags**: Add `#opensource` for open-source tools

### Example Entry
```markdown
- **[Kubernetes](https://kubernetes.io)** - Container orchestration platform #opensource
```

### Ordering
- Categories: Logical workflow order (planning → deployment → monitoring)
- Tools within categories: Alphabetical order
- Subcategories: Most popular/important first

## Pull Request Process

1. **Fork the repository**
2. **Create a feature branch**
   ```bash
   git checkout -b add-toolname
   ```
3. **Make your changes**
   - Add tool in appropriate category
   - Maintain alphabetical order
   - Check spelling and links
4. **Commit with clear message**
   ```bash
   git commit -m "Add [ToolName] to [Category]"
   ```
5. **Push and create PR**
   ```bash
   git push origin add-toolname
   ```

### PR Title Format
- Adding tool: `Add [ToolName] to [Category]`
- New category: `Add new category: [CategoryName]`
- Fix/Update: `Fix: [Description]` or `Update: [Description]`

## What We're Looking For

### High Priority Additions
- 🚀 Emerging tools gaining adoption
- 🔧 Tools filling gaps in current categories
- 🌟 Innovative solutions to common problems
- 📊 Comparison tables for tool categories
- 📚 Learning resources and tutorials

### Always Welcome
- Bug fixes (broken links, typos)
- Better descriptions
- Category reorganization (with discussion)
- Additional context or use cases

## Guidelines

### Do's
- ✅ Research the tool before adding
- ✅ Verify all links work
- ✅ Keep descriptions neutral and factual
- ✅ Include both commercial and open-source options
- ✅ Add context about tool's primary use case
- ✅ Check for duplicates

### Don'ts
- ❌ Add promotional/marketing language
- ❌ Include affiliate links
- ❌ Add tools in beta/alpha without noting it
- ❌ Submit tools you haven't used or researched
- ❌ Add personal opinions or comparisons
- ❌ Remove tools without discussion

## Reporting Issues

### For Broken Links
Create an issue with:
- Tool name and category
- Current broken link
- Suggested replacement (if available)

### For Incorrect Information
Create an issue with:
- What's incorrect
- Correct information
- Source/reference

### For Suggestions
Use issue templates for:
- New categories
- Major reorganizations
- Policy changes

## Code of Conduct

- Be respectful and professional
- Welcome newcomers
- Provide constructive feedback
- Focus on improving the resource
- No spam or self-promotion without disclosure

## Review Process

PRs are reviewed for:
1. **Relevance** - Is it DevOps-related?
2. **Quality** - Is the tool production-ready?
3. **Formatting** - Does it follow guidelines?
4. **Duplicates** - Is it already listed?
5. **Category** - Is it in the right place?

## Questions?

- Open an issue for discussion
- Tag maintainers for urgent matters
- Check existing issues first

## Recognition

Contributors will be recognized in:
- GitHub contributors list
- Special mentions for significant contributions
- Community spotlight for major improvements

Thank you for helping make this resource better for the DevOps community! 🚀
